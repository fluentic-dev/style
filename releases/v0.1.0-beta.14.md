# @fluentic/style v0.1.0-beta.14

This beta fixes production `getToken()` failures for ordinary tokens and value
scales, preserves token bindings in extracted styles, and gives named tokens
global names without runtime hashing.

## Changes

- Compile `createToken()` where it is defined, including its CSS variable name.
- Compile `createTokens()` into nested objects of extracted token leaves. Nested
  array defaults remain single tokens; top-level arrays remain value-keyed maps.
- Compile `createValues()` into prebuilt token entries and a small lookup function.
  Labels, numeric conversion, IDs, and CSS names are calculated at build time.
  Runtime lookups retain key types, token identity, and override behavior.
- Preserve token references in extracted styles, slots, chains, and scope token
  overrides instead of reconstructing those source tokens at each usage.
- Support standalone/module-level `getToken()` on compiled tokens, including
  imported/re-exported value scales and custom style factories.
- Preserve original array/object default references and hoisted dynamic bindings.
  Unused compiled factory calls are marked pure for bundler tree-shaking.
- Resolve named re-exports during compiler tracing and use the compiler's naming
  format when evaluating `getToken()`.
- Remove naming/hash/config dependencies from named-token construction. Named
  tokens retain their lazy proxy behavior and remain an optional dialect import.

## Named-token migration

`createNamedTokens('app.color', { accent: '#2563eb' }).accent` now uses
`--token-app-color-accent`, without a hash. `tokenNameFormat` and `hashLength` do
not affect explicitly named tokens. Identical namespaces and field paths share
one global variable; their individual fallback values may differ.

Namespace dots delimit segments, and segments are joined with `-`. Within a
segment, characters other than ASCII letters and digits are encoded as `_x<hex>_`
using their Unicode code point, including hyphens and underscores. For example,
`tokens['a-b'].c` and `tokens.a['b-c']` have distinct names. A literal dot in an
object key is encoded rather than treated as a path separator.

Rebuild applications and shared style packages together. Update manually written
CSS or external integrations that reference the previous hashed named-token
variables. Ordinary token naming remains configurable.

Extraction requires statically resolvable factory inputs; unresolved factories
produce a build-time diagnostic. Value-scale keys and override values can vary at
runtime. Token-definition modules must pass through extraction too; include
uncompiled dependency source in the plugin transform configuration. Pure
runtime/dev factories retain their existing authoring behavior.

## Validation

- `pnpm install --frozen-lockfile` passed with the pinned pnpm 10.17.1.
- `pnpm release:check` passed on the final implementation: package/declaration
  build, lint, formatting, documentation checks, all workspace TypeScript checks,
  383 library/compiler/runtime tests, example and benchmark production builds,
  Next.js production verification, and packed-package checks.
- The beta.14 tarball passed strict Bundler, Node16, and NodeNext ESM declaration
  consumers with `skipLibCheck: false`, plus React, Preact, Solid, and Tailwind
  consumer builds. Public type exports use generated declarations.
- Generated example snapshots were verified and their TypeScript compiled.
- Regression tests execute compiled module initializers, including the original
  shared-border pattern with imported/re-exported values and a custom factory.
  They also cover group leaves, defaults, spreads, lookup identity, numeric
  conversion, overrides, hoisting, named-token collisions, and invalid inputs.

## Bundle measurements

Reproducible with `pnpm --filter @fluentic/style report:bundle` after building:
Vite production minification, gzip level 9, KiB = 1,024 bytes.

- Extracted production runtime surface: 4.98 KiB gzip.
- Extracted JSX runtime: 2.78 KiB gzip.
- Generated helpers, including `createExtractedValues`: 878 B gzip.
- Full optional named-token API: 1.20 KiB gzip.

Rows measure independent bundles and are not additive. Named-token helpers stay
in the optional dialect subpath. These measurements exclude application token
and style definitions, generated CSS, and external React imports. See the bundle
size documentation for the exact measured runtime surface.
