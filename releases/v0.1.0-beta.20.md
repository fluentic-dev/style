# @fluentic/style v0.1.0-beta.20

This beta reduces generated CSS by using direct token variables and grouping
consecutive rules in the same cascade layer.

## Changes

- Token-valued properties read `var(--token-name, fallback)` directly, without an
  extra property-local variable. Dynamic non-token properties keep local variables.
- `combineStyle` applies token overrides to the token variable on each consuming
  element. Unspecified tokens remain unset, preserving inherited theme values and
  avoiding self-referential custom properties. Token aliases remain supported.
- Consecutive rules in the same layer share a wrapper without changing rule order
  or merging across intervening layers.
- Layer order is declared once, with each parent's sublayers grouped after it:
  `@layer reset, reset.important, global, global.important, css, css.important;`.
- Retain empty managed `.important` reservations. Browser verification showed that
  omitting one can change the winner when important styles are loaded later.

## Documentation

- Add the guided documentation app and share the playground implementation across
  both documentation apps.
- Expand compiler-hoisting guidance and framework integration documentation.

## Migration and limitations

Rebuild extracted applications with this compiler and its matching runtime.
Token overrides now share one value per token per element and inherit into
children. Composing conflicting overrides of the same token no longer isolates
values by property. Use separate tokens when foreground and background need
independent values; scope shared overrides to the appropriate consuming element.
`combineStyle` does not automatically move overrides onto a component root.

| Development runtime                 |           29,913 |                 -19 |

The extracted runtime increase includes checks that avoid setting a token variable
to a reference to itself when no matching override exists. See
`reports/bundle-size.md` for every measured entry.

## Validation

- Passed eight native Chrome cascade checks: normal precedence, managed important
  precedence, reversed important sibling order, grouped source order, late important
  insertion with and without reservations, inherited themes, and inherited overrides.
- Added regression coverage for aliases, removing overrides, shared token values,
  nested layer order, and grouping boundaries.
- `pnpm release:check` passed: package build, current-version bundle measurements,
  workspace lint/format/docs/type checks, library and bundle-report tests,
  example/benchmark builds, Next.js production route checks, and packed consumers.
- Packed exports use generated declarations. Strict TypeScript 5.9 and 7 consumers
  passed Bundler, Node16, and NodeNext resolution; packed React, Preact, Solid,
  and Tailwind example builds passed.
- Both documentation applications passed their production builds.
- Initial workspace validation found formatting issues in two pre-existing docs
  files; formatting was corrected and the complete release gate then passed.
