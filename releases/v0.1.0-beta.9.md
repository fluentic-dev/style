# @fluentic/style v0.1.0-beta.9

## Fixes

- Resolve TypeScript path aliases when statically extracting imported theme values.
- Imported `createValues(...)` palettes referenced through `tsconfig` paths now extract correctly, including in React Server Component production builds.

## What failed and what changed

A theme imported through a relative path could be evaluated while the same theme
imported through a TypeScript alias such as `@/styles/theme` remained unresolved.
In affected RSC production output, imported palette calls could lose their token
variable bindings, leaving CSS values missing or invalid.

The compiler file resolver now discovers TypeScript configuration automatically
and uses its path mappings during static import tracing. Regression coverage
extracts an imported `createValues` palette through an `@/*` alias. Existing alias
imports need no rewrite; rebuild with this version to apply the fix.

This addresses import resolution. The later beta.14 fix separately transforms
ordinary token factories at their definitions so standalone `getToken()` calls
receive extracted metadata.
