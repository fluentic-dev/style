# @fluentic/style v0.1.0-beta.17

This beta reduces compiler work during builds and adds package-name filtering
with native Vite transform-hook filtering.

## Changes

- Evaluate local bindings and imported exports only when style compilation needs
  their values, avoiding unrelated icon maps, schemas, and dependency graphs.
- Preserve lazy initializers' declaration environments when names are shadowed.
  Retain cycle handling, named and star re-exports, and transitive dependency
  invalidation.
- Reuse dependency content hashes within each compilation, resetting them before
  the next compilation so changed dependencies are checked again.
- Skip the runtime-import rewrite pass when no relevant import prefix or escaped
  specifier is present. Evaluated bindings remain memory-only; this release does
  not add a persistent cache of completed transforms.
- Add `includePackages` and `excludePackages` for exact npm package names.
  Package exclusions win over package inclusions, matching inclusions override
  file filters for JavaScript/TypeScript files, and unmatched files retain the
  existing filter behavior.
- Derive Vite's native hook prefilter from the same options, retain the shared
  filter for compatibility, and skip the per-transform sidecar await in production.
- Allow package opt-ins through the webpack/Next.js outer loader exclusions.

## Migration

No configuration changes are required. Optional package filters accept a string
or array of strings:

```ts
fluenticStyle({
  includePackages: ['@acme/ui'],
  excludePackages: ['legacy-ui'],
});
```

Names are exact: globs, versions, and package subpaths are not accepted. Matching
uses the innermost `node_modules` package directory, including pnpm and Windows
layouts. Use file patterns for linked sources resolved outside `node_modules`.
Package inclusion selects script files, not CSS or JSON assets. These options
filter transform targets; imported values needed for extraction remain traceable.

## Build performance

Local application checks reduced Vite build time from approximately 5.9 seconds
to 3.6–4.0 seconds, with style callback time falling from approximately 4.3 seconds
to 2.0–2.1 seconds. Native filtering reduced style callback invocations from 3,398
to 432. Results depend on the application, environment, and other plugins; they
are observations, not a performance guarantee.

## Validation

- `pnpm install --frozen-lockfile` passed with pnpm 10.17.1.
- The versioned package build and `pnpm report:bundle:update` passed. The release
  gate confirmed the measurements match beta.17 and the current build.
- Workspace lint, formatting, documentation checks, and typechecks passed.
- Library/compiler/runtime and bundle-report tests passed, including package
  precedence, native Vite filtering, lazy evaluation, shadowed bindings, cycles,
  re-exports, and dependency invalidation.
- Example and benchmark builds passed. Next.js production verification confirmed
  extracted CSS and rendered routes for `/`, `/ssg`, `/ssr`, `/rsc`, and `/client`.
- The packed beta.17 package passed strict TypeScript 5.9 and 7 consumers with
  Bundler, Node16, and NodeNext resolution. Public types use generated
  declarations without loading implementation sources. React, Preact, Solid,
  and Tailwind tarball consumer builds passed.
- `pnpm release:check` passed end to end.
