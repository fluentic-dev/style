# @fluentic/style v0.1.0-beta.1

This patch beta improves typed selector authoring and documentation.

### Changes

- Add `createSelectorAssert` for typed custom selector validators.
- Keep the public beta API moving with small usability refinements after `0.1.0-beta.0`.

## Typed selector validation

`createSelectorAssert<Arg>(validator)` describes the accepted string argument type
and returns the supplied validator with Fluentic's selector-assert type. The
validator performs runtime validation and throws for invalid values; the generic
argument constrains typed authoring. It does not generate validation from a
TypeScript type.

This is an additive selector-authoring helper. Existing selectors do not need to
be rewritten to use it.
