# @fluentic/style v0.1.0-beta.16

This beta fixes automatic JSX compilation when a `key` follows spread props.

## Changes

- Export `@fluentic/style/plugin/jsx` and `@fluentic/style/jsx`, allowing compilers
  to import `createElement` from the configured JSX import-source base path.
- Reuse Fluentic's wrapped `createElement` so fallback elements retain CSS prop
  transformation, explicit keys, and children.
- Route the plugin base export through development/production and React Server
  Component conditions. The runtime-only base keeps the existing runtime-only
  subpaths' server restriction.
- Resolve the new public type exports to generated declarations.
- Add packed-consumer coverage for compiler-generated fallback imports, runtime
  condition selection, keys, children, and CSS prop removal.

## Migration

No source changes are required. JSX such as
`<TableHeaderCell {...cellProps(c.id)} key={c.id} />` can resolve the compiler's
fallback import directly. Scanner overrides added solely to work around the
missing JSX base export can be removed.
