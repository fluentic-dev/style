# @fluentic/style v0.1.0-beta.8

### Fixes

- Improved Next.js App Router development stability for React Server Components.
- Fixed cases where development CSS could be incomplete on the initial render when styles used imported theme values.
- Reduced the chance of readable development class-name collisions in large stylesheets.
- Improved development cache invalidation when switching between local package builds.

### Notes

This release focuses on development-mode correctness and stability. Production class names and explicit `hashLength` configuration behavior are unchanged.

## Additional implementation details

- RSC development CSS precollection includes imported `createValues(...)` and
  named-token `getToken(...)` values.
- Local CSS-variable identities use stable project-relative callsites, including
  values imported from shared theme modules.
- The Next.js cache key includes the installed package identity so changing a
  local package or tarball invalidates its development CSS cache.
- The default development/debug hash suffix increases from three to five
  characters. Explicit `hashLength` settings and production class names retain
  their previous behavior.

This development fix is separate from the production import-alias fix in beta.9
and the production stylesheet-URL fingerprinting fix in beta.11.
