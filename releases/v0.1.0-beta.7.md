# @fluentic/style v0.1.0-beta.7

This beta fixes an issue where React projects using Fluentic’s JSX runtime could be forced to install optional framework peers.

### Fixes

- React/Next projects using `jsxImportSource: "@fluentic/style/plugin/jsx"` no longer require `preact` to be installed during TypeScript checking.
- Preact and SolidJS JSX `css` prop types are now opt-in instead of being loaded by the default React-oriented type bundle.

### New Type Entry Points

Preact projects should add this once in a project declaration file:

```ts
import '@fluentic/style/types/preact';
```

SolidJS projects should add this once in a project declaration file:

```ts
import '@fluentic/style/types/solid';
```

React projects do not need any extra type import; React JSX `css` prop types remain included by default.

## Migration scope

Place the appropriate import in a declaration file included by the application's
`tsconfig.json`. These imports activate types; they do not replace the framework's
runtime or install the framework itself. React-only consumers should not add the
Preact or Solid imports merely to satisfy Fluentic's default JSX types.
