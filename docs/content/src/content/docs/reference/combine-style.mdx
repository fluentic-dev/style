---
title: combineStyle
description: Merge component styles, slot themes, token themes, and css props.
---

Pass plain styles directly to the `css` prop:

```tsx
<button css={styles.root}>Save</button>
```

Use `combineStyle` when a render also needs scopes, incoming themes, or token
overrides:

```ts
import { combineStyle } from '@fluentic/style';

const css = combineStyle(styles, primary(styles.root));
```

The returned object mirrors the input style object and carries the combined
inputs:

```tsx
<button css={css.root}>
  <span css={css.label}>Save</span>
</button>
```

When the first argument is one attachable style value, such as a style, slot, or
selector sheet, `combineStyle(...)` returns a `StyleProp` directly:

```ts
const css = combineStyle(selectSheet, props.theme, props.compact && compactSheet);
```

Use that result anywhere a `css` prop is accepted:

```tsx
<div css={css} />
```

Arrays of attachable values are also resolved into one `StyleProp`, with later
items winning by the same atomic dedupe rules:

```ts
const css = combineStyle([selectSheet, menuSheet], props.theme);
```

## Variants

For a single resolution step, prefer plain `combineStyle(...)`. The variants are
only conveniences for reuse-heavy shapes.

Use `combineStyle.for(styles)` when the style object is stable and the incoming
themes or overrides change at render time:

```ts
const combine = combineStyle.for(styles);

const css = combine(props.theme, props.compact && compactScope);
```

Use `combineStyle.with(...)` when the incoming themes or overrides are already
known and you need to apply that same set to multiple independent style values or
style objects:

```ts
const combine = combineStyle.with(
  props.theme,
  props.compact && compactSheet,
);

const root = combine(rootSheet);
const menu = combine(menuSheet);
```

For a single style object, this is equivalent to passing the object as the first
argument to `combineStyle(...)`:

```ts
const css = combineStyle.with(props.theme)(styles);
const same = combineStyle(styles, props.theme);
```

Use `combineStyle.multi([...], ...)` when you have a short inline batch of
independent style values and do not need named fields:

```ts
const [root, menu] = combineStyle.multi(
  [rootSheet, menuSheet],
  props.theme,
);
```

`multi(...)` is array-only. It resolves each item independently and keeps the
array itself out of the cache key.

For how `combineStyle(...)` and the `css` prop walk and cache style graphs, see
[Runtime Resolution And Cache](../design/runtime-resolution-and-cache).
