---
title: PreactJS
description: Configure Fluentic Style with Preact and Vite.
---

Use the PreactJS integration when you want Fluentic's `css` prop in a
client-side Preact app.

Unlike React projects, Preact projects do not switch `jsxImportSource` to
`@fluentic/style/plugin/jsx`. Keep Preact's normal automatic JSX runtime. The
Fluentic Vite adapter sees `css={...}` before the Preact preset runs and
compiles it into Preact's normal `class` and `style` props.

Install the package:

<Tabs items={['pnpm', 'npm', 'Yarn', 'Bun']}>
  <Tab>

```sh
pnpm add @fluentic/style preact
pnpm add -D @preact/preset-vite vite
```

  </Tab>
  <Tab>

```sh
npm install @fluentic/style preact
npm install -D @preact/preset-vite vite
```

  </Tab>
  <Tab>

```sh
yarn add @fluentic/style preact
yarn add -D @preact/preset-vite vite
```

  </Tab>
  <Tab>

```sh
bun add @fluentic/style preact
bun add -d @preact/preset-vite vite
```

Add the Fluentic Vite adapter before the Preact plugin and enable the Preact
css-prop preset. The order matters: Fluentic should transform the `css` prop
while the file is still JSX, then Preact can compile the JSX as usual.

```ts title="vite.config.ts"
import { CssPropPresets, plugin as stylePlugin } from '@fluentic/style/plugin/vite';
import preact from '@preact/preset-vite';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [
    stylePlugin({
      cssProp: CssPropPresets.Preact,
    }),
    preact(),
  ],
});
```

Configure TypeScript the same way you normally would for a Preact Vite app.
`jsxImportSource` stays `preact`, not Fluentic:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "preact"
  }
}
```

Then write normal Fluentic styles:

```tsx title="src/App.tsx"
import { style } from '@fluentic/style';

const card = style({
  padding: 16,
  borderRadius: 8,
  backgroundColor: '#fff',
}).hover({
  boxShadow: '0 12px 30px rgb(15 23 42 / 0.16)',
});

export function App() {
  return <section css={card}>Styled by Fluentic.</section>;
}
```

The adapter is compiler plumbing. Application code should use `style(...)` and
`css={...}`. You should not import a Fluentic JSX runtime or call low-level
class-name helpers for normal Preact elements.

In short:

```txt
Preact JSX config stays Preact
Fluentic Vite adapter compiles css={...}
@preact/preset-vite compiles the remaining JSX
```

See `examples/preact-basic` for a minimal Vite app.
