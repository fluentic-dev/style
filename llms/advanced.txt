# Fluentic Style: extensions and interop

## Custom Style Functions

Use `createStyleFn` only when a design system needs custom style properties,
selectors, or transforms.

```ts
type UiStyle = CSSProperties & {
  elevated?: boolean;
  pill?: boolean;
};

const uiSelectors = selectorPriority({
  ...MinimalSelectors,
  pressed: selector('[aria-pressed="true"]'),
  tone: selector('[data-tone="$"]', assertEnumSelector('brand', 'danger')),
}, [
  'hover',
  'pressed',
  'active',
  'disabled',
]);

const uiTransform = styleTransform<UiStyle>({
  transform(style) {
    const { elevated, pill, ...css } = style;
    if (elevated) css.boxShadow = '0 18px 44px rgba(15, 23, 42, 0.12)';
    if (pill) css.borderRadius = 999;
    return css;
  },
});

export const { style: ui } = createStyleFn({
  style: type<UiStyle>,
  selectors: uiSelectors,
  transform: uiTransform,
});
```

Custom builders expose the same shape as `style`: `ui(...)`, `ui.slot(...)`,
`ui.scope(...)`, `ui.raw(...)`, `ui.plain(...)`, `ui.keyframes(...)`, and
`ui.merge(...)`.

Register custom style functions with compiler plugins through `importSources`.

---

## Register custom builders for extraction

```ts
import { ui } from './src/style';
// In the selected bundler plugin options:
const options = {
  importSources: [{ source: './style', name: 'ui', styleFn: ui }],
};
```

source must match the module specifier in app imports, name the exported builder, and styleFn the actual function. Next.js accepts options as stylePlugin(nextConfig, options). Keep shared token data separate from compiler transform modules.

## Class-name-only boundaries

```tsx
import { getClassName } from '@fluentic/style';
const result = getClassName(props.css);
// Pass both outputs; dynamic values may require result.style.
return <ThirdParty
  className={result.className}
  style={result.style}
/>;
```

getClassName returns an object, not a string. getToken(tokenOrValue) returns a CSS variable/fallback string for a token and passes a literal through. Do not treat the returned CSS variable as a resolved color for canvas or another non-CSS consumer.

Use style.keyframes({from: {opacity: 0}, to: {opacity: 1}}) for animations. For named CSS at-rules, selector sheets, global rules, fonts and portal-owned vendor selectors, use the matching public API from @fluentic/style/css rather than inventing a style.global API. Keep existing reset/font CSS until deliberately ported.

## Selector sheets and named layers

Import createSheet from @fluentic/style/css and style from @fluentic/style. Only the individual createSheet option accepts boolean | string; global css.layer.sheet remains boolean.

- Omitted/undefined: inherit css.layer.sheet (default false). css.layer: true alone does not enable sheet layers.
- false: unlayered, overriding the global setting.
- true: <layerNamespace>.sheet.
- 'reset': absolute layer reset, unchanged by the namespace.
- '.reset': relative layer <layerNamespace>.reset (css.reset by default).
- 'vendor.reset': absolute nested layer vendor.reset; '.reset.forms' is relative.

Prefer style.selector(selector, styles) for inline sheet items. The curried style.selector(selector)(styles) form and reusable targets such as const h1 = style.selector('h1'); h1(styles) are also valid and supported by compiler extraction, including chained conditions.

Explicit true/string options still work when css.layer is false. Use nonempty dot-separated identifier names, not @layer syntax, comma lists, or whitespace.

```tsx
import { style } from '@fluentic/style';
import { createSheet } from '@fluentic/style/css';

const reset = createSheet({ layer: 'reset' }, [
  style.selector(['&', '&::before', '&::after', '*', '*::before', '*::after'], {
    boxSizing: 'border-box',
  }),
  style.selector('&', { margin: 0 }),
]);
const app = <div css={reset}>{/* app content */}</div>;
```

Attach to body when body itself must be reset, or use createStyleTarget for an existing DOM element. The generated class scopes every selector: '&' targets the attached element; plain selectors target descendants. Naming a layer does not make selectors global or reach ancestors or detached portals.

Set the plugin's css.layers to ['reset', '$layer', 'overrides']. Explicit names keep their configured position and are not duplicated at $layer. For a relative name, list the resolved name, e.g. css.layers: ['fluentic.reset', '$layer'] with css.layerNamespace: 'fluentic' and sheet layer: '.reset'. The ordering list does not resolve leading dots. Later layers win for normal declarations; normal unlayered CSS outranks layered CSS regardless of sheet weight. Important declarations reverse layer order.
